# Admin Auth Backend Implementation Plan

## Current State
- Admin model exists but **missing** `resetToken` and `resetExpires` fields
- All other admin files (repository, service, controller, routes, DTOs, validators, entity, bindings) are **empty**
- DI types (`types.ts`) doesn't include admin symbols

## Implementation Order

### Step 1: Update Admin Model
**File:** `server/src/models/admin.model.ts`
- Add `resetToken: String` and `resetExpires: Date` fields

### Step 2: Add Admin DI Symbols
**File:** `server/src/core/di/types.ts`
- Add: `AdminRepository`, `AdminAuthService`, `AdminAuthController`

### Step 3: Admin Entity
**File:** `server/src/entities/admin.entity.ts`
- Create `AdminEntity` type matching the model

### Step 4: Admin Repository Interface
**File:** `server/src/core/interfaces/repositories/IAdminRepository.ts`
- Define methods: `findByEmail`, `findByResetToken`, `updateResetToken`, `clearResetToken`, `updatePassword`

### Step 5: Admin Repository
**File:** `server/src/repositories/admin.repository.ts`
- Extend `BaseRepository<AdminEntity>`
- Implement all repository methods

### Step 6: Admin Service Interface
**File:** `server/src/core/interfaces/services/admin/IAdminAuthService.ts`
- Define: `register`, `login`, `forgotPassword`, `resetPassword`

### Step 7: Admin DTOs
**File:** `server/src/dto/admin/admin-auth.dto.ts`
- Types: `RegisterAdminDTO`, `LoginAdminDTO`, `ForgotPasswordDTO`, `ResetPasswordDTO`, `AuthResponseDTO`, `MessageResponseDTO`

### Step 8: Admin Validators
**File:** `server/src/validators/admin-auth.validator.ts`
- Zod schemas: `RegisterAdminSchema`, `LoginAdminSchema`, `ForgotPasswordSchema`, `ResetPasswordSchema`

### Step 9: Admin Mapper
**File:** `server/src/mappers/admin.mapper.ts`
- `AdminMapper.toSecureResponse()` — strip password, resetToken

### Step 10: Admin Service
**File:** `server/src/services/admin/admin-auth.service.ts`
- Implement auth logic following influencer pattern

### Step 11: Admin Controller Interface
**File:** `server/src/core/interfaces/controllers/admin/IAdminAuthController.ts`
- HTTP handler method signatures

### Step 12: Admin Controller
**File:** `server/src/controllers/admin/admin-auth.controller.ts`
- Inject service via DI, handle request/response

### Step 13: Admin Routes
**File:** `server/src/routes/admin/admin-auth.routes.ts`
- POST `/register`, `/login`, `/forgot-password`, `/reset-password`

### Step 14: Admin Bindings
**File:** `server/src/core/di/bindings/admin.bindings.ts`
- Inversify bindings for admin repository, service, controller

### Step 15: Register Routes
**File:** `server/src/index.ts`
- Import and mount: `app.use('/api/admin/auth', adminAuthRoutes);`
